# 物盒册 · 现有版本功能清单（截至 v1.0.3）

> 本文档描述应用当前的完整功能面，作为后续迭代的功能基线。
> 新增/变更功能时请同步更新本文档与 `CHANGELOG.md`。

## 产品定位

个人物品资产与收纳空间管理：把家里「有什么、在哪、值多少、多久没用、该处理什么」
变成一本可查的账。完全离线运行，数据仅存本机。

## 功能模块

### 1. 总览（工作台首页）

| 功能 | 说明 |
|---|---|
| 问候与日期 | 按时段问候（早上好/下午好…）+ 中文日期星期 |
| 4 张统计卡 | 物品总数（条目数/总数量/未归位数）、资产总值（单价×数量）、空间平均利用率（节点数/总容量）、待整理提醒数（闲置件数） |
| 空间概览 | 每个房间的已放件数与利用率进度条（≥90% 变琥珀色警示），可跳转空间页 |
| 分类分布 | 自绘环形图（按条目数）+ 图例（Top5），可跳转分析页 |
| 最近添加 | 最新入库 5 条（缩略图/名称/位置/价值），点击进详情 |
| 整理提醒 | 优先级最高的 3 条建议摘要，可跳转建议页 |

### 2. 物品库

**浏览与检索**
- 搜索：名称、分类、位置路径、标签、备注全文匹配
- 状态筛选：全部（默认排除已处理）/ 在用 / 闲置 / 借出 / 已处理
- 排序：最近添加 / 价值从高到低 / 最久未使用 / 名称
- 分类 chips：横向滚动、带彩色圆点与计数
- 双视图：网格（宽屏 4 列 / 窄屏 2 列，含缩略图、状态徽章、数量角标 ×N）与列表行
- 卡片快捷操作：记一次使用、编辑；点击卡片进详情

**物品详情（宽屏对话框 / 窄屏底部面板）**
- 头图（有照片显示照片，无图显示分类色占位）
- 元信息 6 格：数量、单价/总价值、购入日期、保修截止、最近使用、录入时间
- 标签行、备注全文
- 使用记录时间线（最近 8 条：使用/借出/归还，颜色区分）
- 操作：记一次使用、标记借出/登记归还（按状态切换）、编辑、查看空间、删除（二次确认）

**物品表单（新增/编辑）**
- 照片：四端统一选图（Android/iOS 拍照+相册；桌面文件选择；Web 相册）
- 字段：名称*、分类、状态、存放位置（树形缩进下拉）、数量、单价、购入日期（日期选择器）、保修期（月）、标签（逗号分隔去重 ≤8）、备注
- 图片统一压缩：最长边 ≤900px、白底压平、JPEG 质量 72 → base64 dataURL 随数据存储

### 3. 收纳空间（三层树）

- 结构：房间（room）→ 区域（area）→ 收纳单元（container），可多层嵌套（收纳单元不可再含子级）
- 统计卡：房间数量、总容量、已归位物品、尚未归位
- 房间卡：利用率进度条（≥90% 警示 / ≥100% 危险色）、工具按钮（添加区域/编辑/删除）
- 区域行：递归缩进展示、迷你利用率条、件数与百分比、逐级添加/编辑/删除
- 删除级联保护：提示将连带删除 N 个子级、M 件物品变为未归位
- 待归位专区：列出未指派物品，一键「指定位置」（树形选择器）
- 空间表单：名称*、类型（房间/区域/收纳单元）、容量（可空）、上级空间（过滤自身子树与收纳单元）

### 4. 整理建议（规则引擎）

按严重度（优先处理/建议整理/可以关注）筛选，全部规则自动生成、可一键执行：

| 规则 | 触发条件 | 可执行动作 |
|---|---|---|
| 借出超期 | 状态借出且 ≥30 天未归还 | 登记归还、查看 |
| 长期未使用 | 非闲置且 ≥ 闲置判定天数（2 倍升级为高优先） | 标记闲置、记使用、查看 |
| 闲置在库 | 已闲置且 ≥60 天 | 处理掉（确认）、记使用、查看 |
| 保修临期 | 距保修截止 ≤30 天 | 查看 |
| 保修过期 | 过期 60 天内 | 查看 |
| 重复购买 | 同分类+去括号同名多件 | 查看同类物品（带词搜索） |
| 空间超载 | 利用率 ≥90%（≥100% 高优先） | 添加收纳单元、查看空间 |
| 未归位 | 有未指派物品（≥5 件高优先） | 去归位 |

附「整理原则」知识卡（固定位置/季度清点/80% 利用率）。

### 5. 数据分析

- 统计卡：在用资产总值、平均单件价值、在用比例、闲置资产价值
- 分类资产价值条形图（按分类色着色，Top8）
- 分类数量分布环形图 + 图例（Top6）
- 房间利用率排行（按利用率降序）
- 物品状态分布（在用/闲置/借出占比条）
- 购入年份分布（了解新旧结构与沉没成本）
- 高频使用物品 Top6（按使用记录次数，可点击进详情）

### 6. 设置

- **数据管理**：导出 JSON 完整备份（与 Web 版互通）、导出 CSV 清单（带 BOM，Excel 直开）、
  从 CSV 批量导入（列别名容错、分类自动创建、空间路径匹配）、导入 JSON 备份（覆盖确认）、
  重置为示例数据、清空全部数据（双重确认）
- **分类管理**：新增/编辑/删除（至少保留 1 个，删除时物品迁移到首个分类）、9 色板选色、各类计数
- **使用偏好**：闲置判定天数（30/60/90/120/180/365）、存储占用估算（含图片数与百分比条）
- **关于**：版本徽章、功能简介、数据规模摘要

### 7. 全局能力

- 自适应外壳：≥960px 左侧栏（含整理建议徽章），窄屏顶部栏 + 底部导航（IndexedStack 保持页面状态）
- 快捷新增：窄屏顶栏「记物品」直达物品表单
- 跨页导航：卡片链接跳转、建议页可带词跳转物品库搜索
- 品牌呈现：墨绿启动屏（冷启动不白屏）、五端统一收纳盒图标
- 提示体系：轻提示（SnackBar）、确认对话框、响应式弹层（宽屏对话框/窄屏底部面板）
- 中文本地化（日期选择器等 Material 组件全中文）

## 数据与存储

- 存储：`shared_preferences`，键 `guiwu.data.v2`（兼容性内部标识，不随应用更名变化）
- 数据结构：items / categories / spaces / settings 四段 JSON，字段与 Web 版完全一致
- 备份互通：Web 版导出 JSON ⇄ 本应用导入导出完全双向兼容
- 数据模型：Item（含使用记录 logs）、Space（parentId 树）、Category（色彩）、Settings（idleDays 等）
- 示例数据：29 件物品、9 分类、17 个空间节点，首次启动即有完整演示
